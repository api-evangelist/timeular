# EARLY (Timeular)

> EARLY (formerly Timeular) is a time-tracking product for individuals and teams. Its public REST API at api.early.app manages activities, live tracking, time entries, reports, tags and mentions, folders, users, leave, and webhook subscriptions. Authentication uses an API Key and API Secret exchanged for a Bearer Access Token. V4 is the current version.

## APIs
- [EARLY (Timeular) Public API — Developer Portal](https://developers.early.app/): REST API docs, published as a public Postman collection.
- Base URL: https://api.early.app/api/v4
